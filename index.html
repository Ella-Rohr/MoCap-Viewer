MoCap Viewer Help:

Upload a .glb file by selecting Upload File and using the play and pause buttons.

How to Pan the Viewer
  • Hold down on the left mouse to rotate around the model.
  • Hold down on the right mouse to pan around the model.
  • Pinch or scroll to zoom in and out.
  • Use the Gizmo in the bottom right to rotate around the model.
Model Location Options

Select a mode before uploading a model to the site.

  • As recorded: Places the model in the location it was in relation to the filming of the original take.
  • Origin: Places the model at the origin (0,0) of the scene
  • Auto offset: Places a secondary model at an offset of 1.5 to the first model
Speed

To increase or decrease the speed of the animation, input any number into the "Speed" box. The default value is 1.

To close select the ? again.
